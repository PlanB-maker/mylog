# My Log

แอปส่วนตัวบน Android สำหรับบันทึกการลา ยอดลาคงเหลือ Timesheet และวันหยุดบริษัท
ทำเป็น PWA เปิดเต็มจอ ใช้งานออฟไลน์ได้

- ข้อมูลเก็บในเครื่อง (localStorage) และซิงค์ขึ้น Google Sheets ของเจ้าของผ่าน Apps Script
- ใน repo นี้ไม่มีข้อมูลส่วนตัวและไม่มีรหัสลับ ลิงก์ซิงค์และรหัสลับกรอกในแอปเท่านั้น

## ไฟล์
- `index.html` ตัวแอป
- `sw.js` service worker สำหรับใช้งานออฟไลน์
- `manifest.webmanifest`, `icons/` สำหรับติดตั้งเป็นแอป
- `apps-script/Code.gs` โค้ดฝั่ง Google Sheets (แก้ `TOKEN` ก่อน Deploy)

## อัปเดตแอป
แก้ไฟล์แล้วเพิ่มเลขเวอร์ชันใน `sw.js` (`VERSION`) เพื่อให้มือถือโหลดเวอร์ชันใหม่
